ثانياً: خصائص الأعداد الحقيقية

لأي أعداد حقيقية a, b, c فإن الخصائص التالية صحيحة دائماً:

الخاصية في عملية الجمع في عملية الضرب
التبديلية a + b = b + a a · b = b · a
التجميعية (a + b) + c = a + (b + c) (a · b) · c = a · (b · c)
العنصر المحايد a + 0 = a = 0 + a a · 1 = a = 1 · a
النظير a + (-a) = 0 = (-a) + a a · (1/a) = 1 = (1/a) · a , a ≠ 0
الانغلاق a + b عدد حقيقي a · b عدد حقيقي
التوزيع a(b + c) = ab + ac   ،   (b + c)a = ba + ca

🔄 قاعدة النظير الجمعي والضربي

  • النظير الجمعي: إشارته هي عكس إشارة العدد الأصلي (ومجموعهما يساوي 0).
  • النظير الضربي: إشارته هي ذات إشارة العدد الأصلي (وحاصل ضربهما يساوي 1)، ويُوجد لأي عدد حقيقي لا يساوي الصفر.
  • مثال الكتاب: للعدد -5/8 نظيره الجمعي هو 5/8، ونظيره الضربي هو -8/5.

✨ تبسيط العبارات الجبرية (مثال 5)

بسط العبارة: 3(2q + r) + 5(4q - 7r)

= 3(2q) + 3(r) + 5(4q) - 5(7r) (خاصية التوزيع)
= 6q + 3r + 20q - 35r (اضرب)
= 6q + 20q + 3r - 35r (الخاصية التبديلية للجمع)
= (6 + 20)q + (3 - 35)r (خاصية التوزيع)
= 26q - 32r (بسط)
